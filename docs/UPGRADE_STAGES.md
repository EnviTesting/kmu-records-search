# Knowledge Records Search Tool — v8.1 refinement

Version 8.1 preserves the established v7.3/v6.12 visual structure and focuses on clarity, findability and reliability.

## Search

- shared controlled vocabulary across Records, Data and News;
- mobile filters initiate results correctly;
- Source institution filter;
- Search within results;
- `+` refinements;
- persistent search context for Spatial Discovery.

## Spatial Discovery

- independent Knowledge records, News coverage and AAQMN toggles;
- media and records remain visually distinct;
- IMA live REST/spatial-layer functionality removed.

## Knowledge Insights

- quantitative charting retained;
- Knowledge Canvas added as a separate tab;
- canvas groups the filtered records into seven evidence/governance baskets and lists institutions represented.

## EMA in the News

- simple dynamic meta-analysis using the cleaned story/article model;
- coverage over time, by topic and by publication;
- fallback value tables;
- searchable story/source view remains separate from official knowledge records.

## Data Search

- promoted to a persistent primary navigation item;
- dedicated filters and shared search terminology;
- 65 catalogue entries after removal of live IMA REST layer entries.
